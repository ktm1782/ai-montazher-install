# Установщик ИИ-монтажёра

Мини-установщик для покупателей ИИ-монтажёра Талгата Кусаинова. Сам продукт лежит в закрытом
репозитории. Этот скрипт создаёт на твоём Mac личный ключ доступа только на скачивание, ждёт,
пока Талгат откроет доступ, скачивает продукт и запускает установку.

**Нужен Mac на чипе Apple (M1 и новее) с macOS 15 Sequoia или новее.**

Запуск — в программе «Терминал» (Cmd+Пробел → «Терминал» → Enter):

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/ktm1782/ai-montazher-install/main/install.sh)"
```

Мини-установщик обращается только к GitHub и, если на Mac нет Homebrew, к официальному
установщику Homebrew. Ключи сервисов ты вводишь позже, на своём Mac, и они никуда не уходят.
